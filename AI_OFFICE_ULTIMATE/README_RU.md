# AI OFFICE ULTIMATE · 1.0

Самостоятельный персональный веб-модуль для преподавателя с исходным кодом и точкой интеграции в Bank Mandarin Pro. Русский интерфейс, светлая минималистичная тема, четыре анимированных пиксельных сотрудника. Это рабочая первая версия перечисленных ниже модулей, а не полная замена Microsoft Office.

## Быстрый запуск

1. Распакуйте весь архив. Установите Node.js 22.13 или новее (рекомендуется Node.js 24 LTS) с https://nodejs.org/.
2. Windows: запустите START_WINDOWS.bat. macOS/Linux: выполните `bash START_MAC_LINUX.sh` в папке программы.
3. Откройте **http://127.0.0.1:8787/ai-office/** — обязательно со слешем в конце. Не открывайте index.html двойным щелчком.
4. Создайте пароль владельца (минимум 10 символов). Сервер оставьте запущенным.
5. Создайте проект, откройте «Подключения», добавьте провайдера, точный идентификатор доступной вам модели и свой API-ключ.
6. Выберите подключение, напишите запрос и отправьте. Для сравнения выберите несколько подключений. Для синтеза выберите главную модель.

Установка npm-пакетов для запуска не требуется: сервер использует встроенные возможности Node, клиентские библиотеки уже вложены. Нужен интернет для запросов к ИИ. Доступность моделей, квоты и стоимость зависят от вашего аккаунта провайдера. Идентификатор модели вводится вручную, потому что доступ у аккаунтов отличается. API-ключи в архиве отсутствуют.

## Что работает

- Проекты: создание, переименование, копирование, архив и восстановление. Файлы, история сообщений и задания привязаны к проектам.
- Подключения MiMo, Groq, OpenAI, Anthropic, Gemini. Несколько ключей одного провайдера поддерживаются. Секреты шифруются на сервере AES-256-GCM; интерфейс получает только маску. Системный промпт, язык, температура и лимит ответа настраиваются.
- Одиночный ответ, параллельное сравнение до четырёх моделей через Promise.allSettled, синтез главной моделью, работа команды с четырьмя ролями. Частичный сбой не уничтожает успешные ответы. Есть остановка, защита от повторной отправки по requestId и лимиты запросов.
- Word Studio: создание DOCX, извлечение текста, список абзацев загруженного DOCX, предложения изменений, принятие/отмена, отмена последнего изменения, скачивание и сохранение новой версии. Исходник сохраняется отдельно. Правка поддерживаемого абзаца изменяет только соответствующий XML-фрагмент; остальные части архива сохраняются.
- Работа с текстом PPTX и простыми ячейками XLSX: импорт, извлечение и ограниченное точечное редактирование. Формулы пересчитывает Excel при открытии.
- Планы занятий, китайский язык HSK 1–6, упражнения и тесты через специализированные инструкции модели. Проверка структуры теста, количества вопросов, дублей и индексов ответов. Выгрузка теста ученика и версии преподавателя с ключами в DOCX.
- Research: подготовка обзоров; при подключении Brave Search — поиск и передача модели ссылок и аннотаций. Без Brave модель работает по приложенным материалам и собственным знаниям, а не имитирует веб-поиск.
- Presentation Studio: генерация структуры слайдов и экспорт настоящего редактируемого PPTX. Excel: экспорт XLSX из JSON-таблицы, простые формулы. Code Builder: генерация HTML, скачивание, изолированный предпросмотр без сетевого доступа.
- Генерация изображений через OpenAI для моделей, возвращающих b64_json. Изображения сохраняются в проект.
- Голос: запись MediaRecorder, локальная очередь аудио IndexedDB, распознавание через OpenAI/Groq, три попытки при временном сбое, повтор вручную, вставка расшифровки. Озвучивание через speechSynthesis браузера.
- DOCX/PPTX/XLSX создаются в браузерном Worker. TXT скачивается непосредственно. PDF — через «PDF / печать» → «Сохранить как PDF».
- Настройки шрифта, размера, полей и подписи для новых Word-документов; шаблоны промптов; JSON-копия истории без ключей и файлов.

## Практическое использование Word

Загрузите DOCX в проект → откройте документ → выберите доступный абзац → измените предложение справа или запросите правку у ИИ → вставьте ответ как предложение → примите → сохраните новую версию. Для новой работы используйте редактор результата и «Word .docx». Текст с `# Заголовком` станет заголовком документа.

Правки не применяются незаметно: пользователь подтверждает их. Сложные абзацы с разными стилями внутри строки, гиперссылками, полями, изображениями, tracked changes и специальными конструкциями блокируются. Исходный файл можно скачать в любой момент.

## Честные границы версии

- Это текстовый редактор абзацев, а не WYSIWYG Word. Нет полной визуализации страниц, произвольного перетаскивания таблиц/картинок, нативных Word-рецензий и гарантированного редактирования любого произвольного Office-файла. Сложные элементы сохраняются в исходном архиве и блокируются для правки. Нестандартные пространства имён XML могут не распознаваться.
- Создание новых DOCX включает текст, заголовки и параметры страницы. Нет полноценного конструктора сложных таблиц и иллюстраций. Готовые таблицы и иллюстрации в исходном DOCX сохраняются при допустимых точечных правках.
- PDF создаётся средствами печати браузера, не jsPDF/pdfmake. PDF, сканы, DOC и RTF можно хранить, но OCR и извлечение их содержимого здесь не реализованы. Для работы с их текстом сначала конвертируйте в DOCX/TXT.
- Исследовательский модуль не подтверждает достоверность публикаций автоматически. Поиск передаёт аннотации, а не полный текст статей. Проверяйте ссылки и выводы. HSK-контент генерирует модель; встроенного официального банка заданий нет.
- Нет потокового показа токенов: ответы появляются по завершении каждой модели. Полный синтез требует дополнительного оплачиваемого запроса. Голосовая очередь повторяет запросы только пока приложение открыто. Голоса зависят от браузера и ОС.
- История и файлы — в локальной серверной SQLite и каталоге .data; запись голоса — в браузере. Это не полностью автономное приложение без сервера. Нет синхронизации браузерных записей между устройствами.
- Приложение не интегрировано в ваш Bank Mandarin Pro: его код и текущая архитектура не предоставлены. Для интеграции используйте вложенный MIMO_INTEGRATION_PROMPT.txt. Сервер предназначен для локального запуска; перед публичным размещением подключите проверенную авторизацию и инфраструктуру Mandarin Pro.

## Данные и резервные копии

Каталог `.data` создаётся при первом запуске. В нём SQLite, оригиналы файлов, хеш пароля и master.key. Не публикуйте его, не добавляйте в git и не отправляйте вместе с исходниками. Для полной резервной копии остановите сервер и скопируйте весь каталог .data в защищённое место. Потеря master.key делает сохранённые API-ключи недоступными. JSON-экспорт из интерфейса не содержит файлов и не является полной резервной копией. Автоматического импорта JSON-копии нет.

На общем компьютере создавайте отдельные профили ОС/браузера: локальные аудиозаписи IndexedDB доступны этому профилю. Для production ключ шифрования следует хранить отдельно от БД в системе секретов сервера.

## Проверка

`npm test` запускает 8 тестов: шифрование, пароли, структура тестов, DOCX и сохранение других частей архива, блокировка сложного Word, XLSX и формулы, PPTX, серверные сценарии (авторизация, Origin, ключи, параллельный частичный сбой, синтез, повтор запроса, изоляция владельцев).

Результат при сборке: **8/8 прошли на Node.js 24.22.1**. Платные API, реальные микрофоны и совместимость с вашими Word-файлами требуют проверки после настройки. Автоматический браузерный прогон не выполнен: в среде сборки отсутствовал установленный Chromium.

## Структура

- public/index.html, styles.css, main.js — интерфейс.
- public/documents.js, worker.js — документы и фоновая обработка.
- public/vendor/ — локальные JSZip, docx, PptxGenJS.
- server/core.mjs — провайдеры, шифрование, промпты, проверки.
- server/app.mjs — API, данные и авторизация.
- server/index.mjs — локальный запуск.
- tests/ — воспроизводимые тесты.
- docs/ — API, интеграция и лицензии библиотек.
